**Historical baseline:** The old `v0.1.0-alpha` testnet candidate is not evidence of the current spend path. Public testnet value is **NO-GO**; Mainnet live value is **NO-GO**.
**Current release status: Production-1 local test-value path is scoped GO after `make production-check` passes on the release SHA; Mainnet live-value transfers remain NO-GO.** An independent external audit is required before Mainnet and has not been performed. Production-1 does not provide public-chain finality or external reorg recovery. All Mainnet proof, authorization, custody, state, integration, and recovery gates remain mandatory.
**Mainnet Release Gate Structure:**
- **Mainnet live-value transfers: NO-GO**, including guarded/TVL-capped operation. The local pinned verifier/profile does not establish Mainnet's complete security, authenticated-finality, issuance/custody, recovery, or end-to-end witness-hiding requirements.

**External cryptographic audit:** NOT PERFORMED for Mainnet; DEFERRED for Testnet (zero financial risk, testnet assets only). That does not convert missing implementation or proof obligations into GO.

## Status rule

Every **pre-launch** gate below has a binary production status. The external-audit row is a mandatory pre-Mainnet criterion and remains not performed. **GO** means the exact gate described has adequate implementation and evidence for its limited scope. It does not automatically approve the complete protocol. **NO-GO** means the release criterion is not met; a green unit-test job or an external audit cannot substitute for missing security behavior.

## Mainnet-only remaining sequence

1. **Keep protocol versions separate.** RFC-02 is normative for V2 only. The CHp4.7 identity/nullifier design is isolated in `docs/theory/spend-relation-v3-candidate.md` as non-normative research material. Do not change frozen V1/V2 formulas or KATs; accept only the exact versioned Production-1 relation, never broader candidate V3 objects.
2. **Close the OpenVM Mainnet security gaps.** Production-1 pins and measures the 1-in/1-out OpenVM path for local test value. Mainnet work must justify a >=128-bit composed bound for a pinned configuration, analyze prover-trace leakage and witness hiding, and measure any parameter/circuit changes. SmallWood, Aurora/libiop and RISC Zero remain retired from this release path.
3. **Re-measure exact Mainnet artifacts after any accepted changes.** Benchmark the pinned CommitV3, NullifierV3/HMAC-SHA3-384, key-commitment opening, anchored output derivation and NK-possession relation. Record pinned source/toolchain, security assumptions, constraints/trace rows, prover and verifier time, peak memory and serialized proof size. Do not change the primitive or profile without a separate reviewed specification and vectors.
4. **Keep authorization scoped to the enforced predicate.** Production-1 proves NK possession for the spent note. Threshold/MPC authorization and independent intended-payee authentication are not implemented or implied. Mainnet release work may only rely on the exact predicate actually enforced in the pinned relation; threshold authorization requires separate authorization and implementation.
5. **Preserve the Production-1 relation boundary.** It is fixed to one input and one output with a depth-63 membership path. Any broader relation or public-input contract requires a new version, complete guest constraints, fixed vectors, pinned verifier and independent cost/security evidence before acceptance.
6. **Compose and test state transitions.** Join authenticated finalized deposit/custody verification -> trusted DepositAuthorization -> proof verifier -> durable atomic ledger; exercise replay, duplicate commitments/nullifiers, races, crash, reorg and recovery. Remove injectable test callbacks from the production composition.
7. **Mainnet remains NO-GO** until all Mainnet-specific gates have evidence on one exact release SHA, adversarial checks pass, an internal threat-model audit closes P0/P1 findings, and an independent external audit is completed. Production-1's local test-value decision does not waive any Mainnet proof obligation.

**Current decision: Production-1 local synthetic test-value path: GO when the release `make production-check` passes; all Mainnet live-value transfers: NO-GO.** External audit is deferred and has not been performed; local test-value acceptance does not provide public-chain finality, Mainnet custody, >=128-bit composed security, or witness hiding.
